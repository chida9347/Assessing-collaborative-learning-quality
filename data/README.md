# Data Directory

- `raw/`: Place OUC-CGE videos here. Organize by class if known (e.g., `Low/`, `Medium/`, `High/`) or keep flat. 
- `processed/`: Cached features, preprocessed data
- `splits/`: Split manifests (`splits.json`)

## OUC-CGE
Primary source: https://github.com/oucyy361/OUC-CGE  
OSF: https://osf.io/brd2c/  
Paper: https://www.nature.com/articles/s41597-025-04987-w

**Note:** Dataset may require manual download/authentication. This project does not auto-download from unofficial sources. Follow official instructions from the dataset providers.
